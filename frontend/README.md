# SwipeIt — фронтенд (демо)

Next.js 16 (App Router, статическая сборка `output: "export"`) + TypeScript +
Tailwind v4 + zustand + TanStack Query, архитектура FSD. Сервера нет: данные
живут в мок-сервере поверх localStorage.

## Запуск

```bash
cd frontend
npm install
npm run dev          # http://localhost:3000
npm run build        # статическая сборка в out/
npx serve out        # посмотреть сборку
```

## Команды

| Команда                                                            | Что делает                                                                |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| `npm run dev`                                                      | Режим разработки (перед стартом копирует каталог)                         |
| `npm run build`                                                    | Статическая сборка в `out/`                                               |
| `npm run lan`                                                      | Сервер режима «Локальная сеть» для теста с друзьями по Wi-Fi (см. ниже)   |
| `npm run catalog:sync`                                             | Копирует `../catalog/` (или заглушку `catalog-stub/`) в `public/catalog/` |
| `npm run check`                                                    | Все проверки: типы, eslint, steiger, prettier, тесты                      |
| `npm run typecheck` / `lint` / `steiger` / `format:check` / `test` | По отдельности                                                            |
| `npm run format`                                                   | Отформатировать всё prettier'ом                                           |

Перед коммитом хук husky прогоняет prettier и `eslint --fix` по изменённым файлам.

## Тест с друзьями по Wi-Fi

Режим «Локальная сеть»: ноутбук становится сервером, друзья открывают
приложение на своих телефонах и видят общие данные — вишлисты, брони, планы,
Санту. Интернет не нужен, нужна одна Wi-Fi на всех.

**1. Запусти на ноутбуке**

```bash
cd frontend
npm run lan
```

Первый запуск дольше — сначала собирается приложение. Потом в терминале
появятся адрес вида `http://192.168.1.34:4000` и QR-код.

**2. Скажи друзьям**

«Подключись к моей Wi-Fi и открой на телефоне этот адрес (или наведи камеру на
QR-код) — сразу откроется лента подарков, имя спросим, когда понадобится».
Каждый телефон — свой
человек; все, кто зашёл, автоматически друзья друг другу и демо-друзьям.

Ноутбук не выключай и не закрывай крышку, пока идёт тест. Остановить сервер —
`Ctrl+C` в терминале. Данные сохраняются в `frontend/.lan-data/` и остаются
после перезапуска.

**Если телефон не открывает адрес**

- Телефон и ноутбук должны быть в **одной** Wi-Fi. Мобильный интернет на
  телефоне не подойдёт.
- Не используй гостевую сеть роутера: она часто не пускает устройства друг к
  другу.
- Windows: когда при первом запуске появится окно брандмауэра, разреши Node.js
  доступ **для частных сетей**. Если окно уже закрыли — «Брандмауэр Защитника
  Windows» → «Разрешить взаимодействие с приложением…» → поставь галочку
  «Частные» у Node.js. И проверь, что сама Wi-Fi в Windows отмечена как
  «Частная сеть», а не «Общедоступная».
- Адресов несколько — попробуй следующий из списка в терминале.
- Порт занят — запусти на другом: `npm run lan -- --port 4100`.

**Чистый лист**

`npm run lan -- --reset` — стереть все данные прошлого теста и начать с
демо-друзей заново. Телефоны начнут с чистого профиля.

> **Важно:** запускай только в своей домашней или офисной Wi-Fi. В публичных сетях
> (кафе, коворкинг) данные увидит любой подключённый: у сервера нет паролей.

## Установить как приложение

Демо по ссылке https://seitek2002.github.io/swipeit/ ставится на телефон как
обычное приложение — с иконкой-бантом и без панелей браузера. После первого
открытия оно работает и без интернета: лента подарков, вишлист, планы и Санта
с демо-друзьями.

**Android (Chrome).** Открой ссылку → меню «⋮» → «Установить приложение» (или
«Добавить на главный экран») → «Установить». Иконка появится среди приложений.

**iPhone (Safari).** Открой ссылку именно в Safari → кнопка «Поделиться»
(квадрат со стрелкой) → «На экран „Домой“» → «Добавить». В других браузерах на
iPhone этого пункта нет.

В режиме «Локальная сеть» (`npm run lan`, адрес `http://192.168…`) установка и
работа без интернета недоступны: браузер разрешает их только на HTTPS. Это
нормально — там приложение и так работает только рядом с ноутбуком.

## Структура

```
frontend/
├── app/            ← только роутинг Next (тонкие page.tsx / layout.tsx)
├── pages/          ← пустая заглушка, см. pages/README.md
├── src/            ← FSD: app → pages → widgets → features → entities → shared
├── lan/            ← Node-сервер режима «Локальная сеть»
├── catalog-stub/   ← каталог-заглушка до прихода данных Товароведа
└── scripts/        ← служебные скрипты (catalog-sync и др.)
```
